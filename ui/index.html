Sim: walk = bounded random walk · increment = counter (energy, uptime) · fixed = static until you override it.
Step depends on the datatype: for float/int it's the max change per tick; for bool/enum/string it's the probability of changing per tick (0–1) — e.g. 0.05 ≈ once every 20s. Greyed-out boxes don't apply to that datatype. A bool publishes real true/false (want 0/1? use an int with min 0 / max 1).
